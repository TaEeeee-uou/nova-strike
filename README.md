# 🚀 NOVA STRIKE

**3D Space Shooter** built with Three.js — playable directly in the browser.

## 🎮 Play

Just open `index_v1.0.0.html` in any modern browser. No installation needed.

## Controls

| Key | Action |
|-----|--------|
| `W` / `↑` | Move up |
| `S` / `↓` | Move down |
| `A` / `←` | Move left |
| `D` / `→` | Move right |
| `Shift` | Boost speed |
| `Space` / `Click` | Fire beam |

## Features

- 🌌 Fully 3D space environment with nebula and starfield
- ☀️ Distant celestial bodies: Sun, Moon, and 5 unique planets
- 👾 3 types of enemies with increasing difficulty
- 🪨 Asteroid hazards
- 🛡 Shield / health system with combo multiplier
- 📈 Level progression system
- ✨ Particle explosion effects

## Tech Stack

- [Three.js r128](https://threejs.org/) (via CDN)
- Vanilla HTML / CSS / JavaScript — single file, zero dependencies
